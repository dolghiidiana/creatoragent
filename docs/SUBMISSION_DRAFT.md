## Inspiration

Creative projects need continuity across sessions. A real creator promotion workflow exposed the need to remember the project's purpose, preserve voice, ground claims in sources and avoid repeated approvals for ordinary preparation. CreatorAgent translates those lessons into a persistent local worker and a consolidated review process. The public demonstration uses original fictional material only.

## What it does

CreatorAgent retains goal, purpose, priorities, identity and voice alongside tasks and evidence. Local preparation continues until a consequential boundary. Explicit simulated approval resumes a fake-destination workflow. Reviewed source metadata separates source statements, quotation, personal experience, interpretation and hypotheses. The prototype does not infer sales demand from writing.

A separately approved competition-runtime task makes a real bounded NVIDIA Nemotron call through Nebius Token Factory, validates it strictly and persists a provenance receipt before local review. On October 10, the actual worker's synthetic count audit returned twelve with exact-match acceptance. Restart with transport disabled reused the receipt without another request.

## How we built it

Python and SQLite provide durable tasks, context, permissions, dependency scheduling, artifacts and recovery. The runtime path is Worker → exact consent and fresh preflight → atomic budget reservation/intent → dedicated Nebius adapter → strict validation → atomic usage/receipt → local review. Source identity, speaker, subjective status and permissions are application-owned. Public execution remains a fake adapter; live model transport is disabled in default reproduction commands.
